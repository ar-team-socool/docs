# แก้ปัญหา

หัวข้อในหน้านี้ตั้งตามข้อความที่ AR Launcher แสดง ทั้งตอนเปิดโปรแกรมและตอนเชื่อมต่อเซิร์ฟเวอร์ หาหัวข้อที่ตรงกับข้อความที่คุณเห็น
ถ้าทำตามแล้วยังไม่หาย ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

## เปิด AR Launcher ไม่ผ่าน [#startup]

ตอนเปิด AR Launcher จะตรวจความพร้อมทีละขั้น ถ้าขั้นไหนไม่ผ่าน จะขึ้นข้อความสีแดงบอกสาเหตุใต้โลโก้ ดูหัวข้อย่อยที่ตรงกับข้อความนั้น
ถ้าข้อความบอกว่าเกิดข้อผิดพลาดที่ไม่คาดคิด สร้างการเชื่อมต่อที่ปลอดภัยไม่สำเร็จ หรือโหลดข้อมูลเซิร์ฟเวอร์ไม่สำเร็จ ให้กด **ลองอีกครั้ง**
ถ้ายังไม่หาย ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### ไม่พบการเชื่อมต่ออินเทอร์เน็ต [#startup-internet]

AR Launcher ไม่พบการเชื่อมต่ออินเทอร์เน็ตของเครื่องนี้ ทำทีละข้อ แล้วกด **ลองอีกครั้ง** หลังทำแต่ละข้อ

1. ดูไอคอนเครือข่ายที่มุมขวาล่างของ taskbar ถ้าขึ้นว่าไม่ได้เชื่อมต่อ ให้คลิกไอคอนนั้น ปิด **Airplane mode** (โหมดเครื่องบิน)
   ถ้าเปิดอยู่ แล้วเลือก Wi‑Fi ที่ใช้ ถ้าใช้สาย LAN ให้ตรวจว่าเสียบสายแน่นทั้งที่เครื่องและที่เราเตอร์
2. กด **Windows + R** พิมพ์ `ncpa.cpl` แล้วกด Enter ถ้าการเชื่อมต่อที่ใช้อยู่ขึ้นว่า **Disabled** ให้คลิกขวาแล้วเลือก **Enable**
3. เปิดเว็บไซต์ใดก็ได้ในเบราว์เซอร์ ถ้าเปิดไม่ได้เหมือนกัน ให้รีสตาร์ทเครื่องและเราเตอร์

ถ้าเปิดเว็บไซต์ได้แต่ AR Launcher ยังขึ้นข้อความนี้ ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### เชื่อมต่อกับระบบของ AR Launcher ไม่สำเร็จ [#startup-connection]

AR Launcher ติดต่อระบบของเราไม่ได้ ส่วนใหญ่เกิดจากโปรแกรมที่เปลี่ยนเส้นทางอินเทอร์เน็ตของเครื่อง
ทำทีละข้อ แล้วกด **ลองอีกครั้ง** หลังทำแต่ละข้อ

1. ปิด VPN และโปรแกรมเร่งความเร็วอินเทอร์เน็ต เช่น โปรแกรมลดปิงสำหรับเกม ให้ปิดทั้งโปรแกรมจากไอคอนมุมขวาล่างของ taskbar
   ไม่ใช่แค่ปิดหน้าต่าง ถ้าต้องการใช้ต่อ ให้เพิ่ม AR Launcher ในรายการยกเว้นของโปรแกรมนั้น
2. คืนค่า DNS เป็นอัตโนมัติ กด **Windows + R** พิมพ์ `ncpa.cpl` แล้วกด Enter คลิกขวาการเชื่อมต่อที่ใช้อยู่ แล้วเลือก
   **Properties** → **Internet Protocol Version 4 (TCP/IPv4)** → **Properties** เลือก
   **Obtain DNS server address automatically** (รับที่อยู่ DNS อัตโนมัติ) แล้วกด **OK**
   ถ้าใช้โปรแกรมเปลี่ยน DNS อยู่ ให้ปิดโปรแกรมนั้นด้วย
3. ล้างค่า DNS ที่เครื่องจำไว้ เปิด **Command Prompt** พิมพ์ `ipconfig /flushdns` แล้วกด Enter
4. รีสตาร์ทเครื่องและเราเตอร์

ถ้าข้อความบอกว่ายืนยันการเชื่อมต่อไม่สำเร็จ ให้ตรวจสอบอินเทอร์เน็ตก่อน แล้วกด **ลองอีกครั้ง**
ถ้าทำครบแล้วยังไม่หาย ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### วันที่หรือเวลาของเครื่องไม่ตรงกับเวลาจริง [#startup-clock]

ใต้ข้อความจะบอกวันเวลาที่เครื่องนี้ใช้อยู่ แก้ให้ตรงด้วยการตั้งค่าของ Windows อย่าตั้งนาฬิกาเอง

1. เปิด **Settings** ของ Windows ไปที่ **Time & language** → **Date & time**
2. เปิด **Set time automatically** (ตั้งเวลาอัตโนมัติ)
3. ถ้าเวลายังผิด ให้เลือก **Time zone** ตามประเทศที่อยู่ เช่น **(UTC+07:00) Bangkok, Hanoi, Jakarta** สำหรับประเทศไทย ถ้าเลือกไม่ได้ ให้ปิด **Set time zone automatically** ก่อน
4. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

### ต้องอัปเดตแต่ยังไม่มีเวอร์ชันใหม่ [#startup-update]

เวอร์ชันที่ติดตั้งอยู่เก่ากว่าเวอร์ชันที่ใช้งานได้ แต่ยังไม่มีเวอร์ชันใหม่ให้อัปเดต ปัญหานี้ไม่ได้อยู่ที่เครื่องของคุณ การติดตั้งใหม่จึงไม่ช่วย
รอสักพักแล้วกด **ลองอีกครั้ง** ถ้ายังขึ้นอยู่ ให้ติดต่อทีมงาน

### ต้องติดตั้ง AR Launcher ใหม่ [#startup-reinstall]

ไฟล์ที่ระบบจับภาพหน้าจอต้องใช้หายไป หรือไม่ตรงกับเวอร์ชันของ AR Launcher ที่ติดตั้งอยู่
ดาวน์โหลดตัวติดตั้งจาก[หน้าติดตั้ง](/th/ar-launcher/install#download) แล้วติดตั้งใหม่ ใช้ไฟล์จากช่องทางอย่างเป็นทางการเท่านั้น

### โปรแกรมป้องกันไวรัสบล็อกระบบจับภาพหน้าจอ [#startup-capture-blocked]

เปิดประวัติการป้องกันในโปรแกรมป้องกันไวรัส แล้วอนุญาตรายการล่าสุดที่ถูกบล็อก
ถ้าใช้ Windows Security (โปรแกรมป้องกันไวรัสที่มากับ Windows) ทำตามนี้

1. กด **Windows + R** พิมพ์ `windowsdefender:` แล้วกด Enter
2. ไปที่ **Virus & threat protection** → **Protection history** (ประวัติการป้องกัน)
3. คลิกรายการล่าสุดเพื่อดูรายละเอียด ถ้า Windows ขออนุญาต ให้กด **Yes**
   อนุญาตเฉพาะรายการที่ไฟล์อยู่ในโฟลเดอร์ที่ติดตั้ง AR Launcher ซึ่งปกติที่อยู่ไฟล์จะมีคำว่า `AR Launcher`
4. กด **Actions** แล้วเลือก **Allow on device** (อนุญาตบนอุปกรณ์) ถ้ามีแต่ **Restore** ให้เลือก **Restore** ก่อน
   แล้วถ้ามีรายการใหม่ของไฟล์เดียวกันขึ้นมา ให้เลือก **Allow on device** ที่รายการนั้น
5. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

ถ้าใช้โปรแกรมป้องกันไวรัสตัวอื่น ให้เปิดหน้าประวัติหรือหน้าไฟล์ที่ถูกกักกัน (quarantine) ของโปรแกรมนั้น แล้วคืนและอนุญาตรายการเดียวกัน
ชื่อเมนูจะต่างกันไปในแต่ละโปรแกรม
ไม่ต้องปิดโปรแกรมป้องกันไวรัส ถ้าไม่มีรายการที่ถูกบล็อก ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### Windows จับภาพหน้าจอไม่ได้ หรือข้อความเรื่อง UAC [#startup-capture-unsupported]

ข้อความเหล่านี้มาจาก AR Launcher รุ่นก่อน 0.26.4 ทั้งเรื่องการจับภาพหน้าจอของ Windows เรื่อง User Account Control (UAC) บริการ Application Information และบัญชี Administrator ที่มากับ Windows

ถ้ายังเห็นข้อความเหล่านี้ ให้[ดาวน์โหลด AR Launcher รุ่นล่าสุด](/th/ar-launcher/install#download)แล้วติดตั้ง
ไม่ต้องเปิด UAC หรือรันคำสั่งที่เคยอยู่ในหัวข้อนี้

### FiveM หรือ RedM เปิดอยู่ตอนเปิด AR Launcher [#startup-fivem-running]

ต้องปิดเกมก่อนเริ่มใช้งาน AR Launcher กด **ปิดเกม** แล้ว AR Launcher จะปิดเกมและตรวจความพร้อมใหม่เอง
ถ้าข้อความบอกว่าปิดเกมไม่สำเร็จ ให้ปิดเกมจาก Task Manager

1. กด **Ctrl + Shift + Esc** เพื่อเปิด **Task Manager** ถ้าหน้าต่างแสดงแค่รายชื่อโปรแกรม ให้กด **More details**
2. ที่ **Processes** คลิกขวารายการที่มีคำว่า FiveM หรือ RedM แล้วเลือก **End task** ทำจนไม่เหลือรายการเหล่านี้
3. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

## ระบบแอนตี้ชีตไม่ทำงาน [#anticheat-not-running]

หน้าต่างนี้ขึ้นเมื่อกดเชื่อมต่อเซิร์ฟเวอร์ที่รับเฉพาะเครื่องที่ระบบแอนตี้ชีตทำงานอยู่
ข้อความในหน้าต่างจะบอกสาเหตุ ดูหัวข้อย่อยที่ตรงกับข้อความนั้น

### ไฟล์ที่ระบบแอนตี้ชีตต้องใช้หายไป [#anticheat-files-missing]

ไฟล์อาจถูกลบไปหลังการติดตั้ง ดาวน์โหลดตัวติดตั้งจาก[หน้าติดตั้ง](/th/ar-launcher/install#download) แล้วติดตั้ง AR Launcher ใหม่
ใช้ไฟล์จากช่องทางอย่างเป็นทางการเท่านั้น

### AR Launcher กำลังขออนุญาตจาก Windows [#anticheat-waiting-for-windows]

กด **ใช่** (Yes) เมื่อ Windows ถาม แล้วกด **ลองอีกครั้ง**
ถ้าไม่เห็นหน้าต่างของ Windows ให้ดูไอคอนที่กะพริบบนแถบงาน

### บัญชี Windows ไม่ใช่บัญชีผู้ดูแลระบบ [#anticheat-not-admin]

ใส่รหัสผ่านของบัญชีผู้ดูแลระบบ (Administrator) ของเครื่องนี้เมื่อ Windows ถาม แล้วกด **ลองอีกครั้ง**
ถ้าไม่ทราบรหัสผ่าน ให้เข้าใช้งาน Windows ด้วยบัญชีผู้ดูแลระบบ หรือขอให้เจ้าของเครื่องช่วย

1. กด **Ctrl + Alt + Delete** แล้วเลือก **Switch user** (สลับผู้ใช้)
2. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบของเครื่องนี้ ถ้าไม่แน่ใจ ให้กด **Windows + R** พิมพ์ `ms-settings:yourinfo` แล้วกด Enter
   ใต้ชื่อบัญชีต้องมีคำว่า **Administrator**
3. ถ้าบัญชีนั้นยังไม่มี AR Launcher ให้[ติดตั้ง](/th/ar-launcher/install#download)ก่อน แล้วเปิด AR Launcher และกด **เชื่อมต่อ** อีกครั้ง

### เครื่องตั้งค่าไม่ให้บัญชีนี้ขอสิทธิ์ [#anticheat-elevation-denied]

เข้าใช้งาน Windows ด้วยบัญชีผู้ดูแลระบบ (Administrator) ของเครื่องนี้ หรือขอให้เจ้าของเครื่องช่วย

1. กด **Ctrl + Alt + Delete** แล้วเลือก **Switch user** (สลับผู้ใช้)
2. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบของเครื่องนี้ ถ้าไม่แน่ใจ ให้กด **Windows + R** พิมพ์ `ms-settings:yourinfo` แล้วกด Enter
   ใต้ชื่อบัญชีต้องมีคำว่า **Administrator**
3. ถ้าบัญชีนั้นยังไม่มี AR Launcher ให้[ติดตั้ง](/th/ar-launcher/install#download)ก่อน แล้วเปิด AR Launcher และกด **เชื่อมต่อ** อีกครั้ง

## การเชื่อมต่อกับเซิร์ฟเวอร์ถูกบล็อก [#connection-blocked]

มีโปรแกรมบนเครื่องหรือในเครือข่ายของคุณบล็อกการเชื่อมต่อของ AR Launcher
ทำทีละข้อ แล้วกด **ลองอีกครั้ง** หลังทำแต่ละข้อ

1. ปิด VPN และโปรแกรมเร่งความเร็วอินเทอร์เน็ต เช่น โปรแกรมลดปิงสำหรับเกม ให้ปิดทั้งโปรแกรมจากไอคอนมุมขวาล่างของ taskbar
   ไม่ใช่แค่ปิดหน้าต่าง ถ้าต้องการใช้ต่อ ให้เพิ่ม AR Launcher ในรายการยกเว้นของโปรแกรมนั้น
2. ถ้าใช้อินเทอร์เน็ตของที่ทำงาน หอพัก หรือร้าน ให้ลองต่อ hotspot จากมือถือ ถ้าเข้าเซิร์ฟเวอร์ได้
   แปลว่าเครือข่ายเดิมบล็อกการเชื่อมต่อ ให้แจ้งผู้ดูแลเครือข่ายนั้น

ถ้าทำครบแล้วยังไม่หาย ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

เกม (FiveM หรือ RedM) ผูกกับบัญชี Steam คนละบัญชีกับที่เข้าสู่ระบบ AR Launcher เซิร์ฟเวอร์จึงปฏิเสธการเชื่อมต่อ
แก้ได้สองทาง

- เปลี่ยนบัญชี Steam ในการตั้งค่าของเกมให้เป็นบัญชีเดียวกับ AR Launcher แล้วกด **ลองอีกครั้ง**
  แล้ว AR Launcher จะเปิดเกมใหม่ให้
- หรือออกจากระบบ แล้วเข้าสู่ระบบ AR Launcher ด้วยบัญชีที่เกมใช้

## ผูกบัญชี Steam กับ FiveM หรือ RedM [#steam-link]

เซิร์ฟเวอร์นี้ต้องใช้บัญชี Steam ที่ผูกกับเกม และต้องเปิดเกมใหม่หลังผูกบัญชี AR Launcher จึงปิดเกมไปก่อน
กด **ลองอีกครั้ง** ถ้าเกมขอให้ผูกบัญชี Steam ให้ใช้บัญชีเดียวกับที่เข้าสู่ระบบ AR Launcher

## ยังเข้าเซิร์ฟเวอร์นี้ไม่ได้ [#cannot-join]

ข้อความในหน้าต่างจะบอกสาเหตุ ดูหัวข้อย่อยที่ตรงกับข้อความนั้น

### AR Launcher ไม่พบ FiveM หรือ RedM [#fivem-not-found]

เปิดเกมนั้นเองหนึ่งครั้ง รอจนถึงหน้าหลักแล้วปิด

1. กดปุ่ม **Windows** พิมพ์ `FiveM` หรือ `RedM` ตามเกมของเซิร์ฟเวอร์ แล้วเปิดเกม
2. รอจนถึงหน้าหลักของเกม ถ้าเปิดครั้งแรกหรือมีอัปเดต เกมจะดาวน์โหลดไฟล์ก่อน ให้รอจนเสร็จ
3. ปิดเกม ถ้าปิดไม่ได้ ให้ปิดจาก Task Manager ตาม[ขั้นตอนนี้](#startup-fivem-running)
4. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

### ไม่พบไฟล์ตั้งค่าของ GTA V [#startup-gta-settings]

ไม่พบไฟล์ตั้งค่า หรือไฟล์อ่านไม่ได้: เปิดเกมผ่าน FiveM หนึ่งครั้งเพื่อให้เกมเขียนไฟล์ตั้งค่าใหม่

1. กดปุ่ม **Windows** พิมพ์ `FiveM` แล้วเปิด FiveM
2. รอจนถึงหน้าหลักของ FiveM ถ้ามีอัปเดต FiveM จะดาวน์โหลดไฟล์ก่อน ให้รอจนเสร็จ
3. ปิด FiveM ถ้าปิดไม่ได้ ให้ปิดจาก Task Manager ตาม[ขั้นตอนนี้](#startup-fivem-running)
4. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

### ตรวจการตั้งค่ากราฟิกไม่สำเร็จ [#settings-unchecked]

กด **ลองอีกครั้ง** ถ้ายังไม่สำเร็จ ให้ตรวจการเชื่อมต่ออินเทอร์เน็ตตาม[ขั้นตอนนี้](#startup-internet)
แล้ว[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### ไม่พบไฟล์ตั้งค่าของ RedM [#redm-settings]

ไม่พบไฟล์ตั้งค่า หรือไฟล์อ่านไม่ได้: เปิด RedM เองหนึ่งครั้งเพื่อให้เกมเขียนไฟล์ตั้งค่าใหม่

1. กดปุ่ม **Windows** พิมพ์ `RedM` แล้วเปิด RedM
2. รอจนถึงหน้าหลักของ RedM ถ้ามีอัปเดต RedM จะดาวน์โหลดไฟล์ก่อน ให้รอจนเสร็จ
3. ปิด RedM ถ้าปิดไม่ได้ ให้ปิดจาก Task Manager ตาม[ขั้นตอนนี้](#startup-fivem-running)
4. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

### เกมไม่ได้เปิดในโหมดตรวจไฟล์เกม (pure mode) [#pure-mode]

กด **ลองอีกครั้ง** เพื่อให้ AR Launcher เปิดเกมใหม่ อย่าเปิดเกมเอง
ถ้าข้อความบอกว่าตรวจไม่ได้และยังเกิดขึ้นอีก ให้รีสตาร์ทเครื่องแล้วลองอีกครั้ง

### FiveM หรือ RedM ไม่ได้อยู่ในช่องทางอัปเดตที่เซิร์ฟเวอร์กำหนด [#update-channel]

กด **ลองอีกครั้ง** แล้วรอให้เกมอัปเดตจนเสร็จ อย่าเปิดเกมเอง

### FiveM หรือ RedM อัปเดตตัวเองแล้วปิดไป [#fivem-updated]

ปิดหน้าต่างแจ้งข้อผิดพลาดของเกม แล้วกด **ลองอีกครั้ง**

### FiveM หรือ RedM หยุดทำงานระหว่างเข้าเซิร์ฟเวอร์ [#fivem-stopped]

มักเกิดจากเกมแครช AR Launcher จึงปิดหน้าต่างเกมที่ค้างอยู่ กด **ลองอีกครั้ง**

## ถูกระงับการใช้งาน [#blocked]

บัญชีนี้ถูกระงับการใช้งาน AR Launcher ถ้าคิดว่าเป็นความผิดพลาด ให้ติดต่อผู้ดูแลเซิร์ฟเวอร์

## ถูกเตะออกจากเกมระหว่างเล่น [#kicked]

<Callout type="info">
  ถ้า AR Launcher ถูกปิด แครช หรือเน็ตหลุด เซิร์ฟเวอร์อาจเตะคุณออกจากเกม เปิด AR Launcher ค้างไว้ตลอดเวลาที่เล่น
</Callout>
