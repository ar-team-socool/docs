# แก้ปัญหา

หัวข้อในหน้านี้ตั้งตามข้อความที่ AR Launcher แสดง ทั้งตอนเปิดโปรแกรมและตอนเชื่อมต่อเซิร์ฟเวอร์ หาหัวข้อที่ตรงกับข้อความที่คุณเห็น
ถ้าทำตามแล้วยังไม่หาย ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

## เปิด AR Launcher ไม่ผ่าน [#startup]

ตอนเปิด AR Launcher จะตรวจความพร้อมทีละขั้น ถ้าขั้นไหนไม่ผ่าน จะขึ้นข้อความสีแดงบอกสาเหตุใต้โลโก้ ดูหัวข้อย่อยที่ตรงกับข้อความนั้น
ถ้าข้อความบอกว่าเกิดข้อผิดพลาดที่ไม่คาดคิด สร้างการเชื่อมต่อที่ปลอดภัยไม่สำเร็จ หรือโหลดข้อมูลเซิร์ฟเวอร์ไม่สำเร็จ ให้กด **ลองอีกครั้ง**
ถ้ายังไม่หาย ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### ไม่พบการเชื่อมต่ออินเทอร์เน็ต [#startup-internet]

ตรวจสอบว่าเครื่องเชื่อมต่ออินเทอร์เน็ตอยู่ แล้วกด **ลองอีกครั้ง**

### เชื่อมต่อกับระบบของ AR Launcher ไม่สำเร็จ [#startup-connection]

ถ้าใช้ VPN โปรแกรมเร่งความเร็วอินเทอร์เน็ต หรือตั้งค่า DNS เอง ให้ปิดก่อน แล้วกด **ลองอีกครั้ง**
ถ้าข้อความบอกว่ายืนยันการเชื่อมต่อไม่สำเร็จ ให้ตรวจสอบอินเทอร์เน็ตก่อน แล้วกด **ลองอีกครั้ง**

### วันที่หรือเวลาของเครื่องไม่ตรงกับเวลาจริง [#startup-clock]

ใต้ข้อความจะบอกวันเวลาที่เครื่องนี้ใช้อยู่ แก้ให้ตรงด้วยการตั้งค่าของ Windows อย่าตั้งนาฬิกาเอง

1. เปิด **Settings** ของ Windows ไปที่ **Time & language** → **Date & time**
2. เปิด **Set time automatically** (ตั้งเวลาอัตโนมัติ)
3. ถ้าเวลายังผิด ให้เลือก **Time zone** ตามประเทศที่อยู่ เช่น **(UTC+07:00) Bangkok, Hanoi, Jakarta** สำหรับประเทศไทย ถ้าเลือกไม่ได้ ให้ปิด **Set time zone automatically** ก่อน
4. กลับไปที่ AR Launcher แล้วกด **ลองอีกครั้ง**

### ต้องอัปเดตแต่ยังไม่มีเวอร์ชันใหม่ [#startup-update]

เวอร์ชันที่ติดตั้งอยู่เก่ากว่าเวอร์ชันที่ใช้งานได้ แต่ยังไม่มีเวอร์ชันใหม่ให้อัปเดต ปัญหานี้ไม่ได้อยู่ที่เครื่องของคุณ การติดตั้งใหม่จึงไม่ช่วย
รอสักพักแล้วกด **ลองอีกครั้ง** ถ้ายังขึ้นอยู่ ให้ติดต่อทีมงาน

### ต้องติดตั้ง AR Launcher ใหม่ [#startup-reinstall]

ไฟล์ที่ระบบจับภาพหน้าจอต้องใช้หายไป หรือไม่ตรงกับเวอร์ชันของ AR Launcher ที่ติดตั้งอยู่
ดาวน์โหลดตัวติดตั้งจาก[หน้าติดตั้ง](/th/ar-launcher/install#download) แล้วติดตั้งใหม่ ใช้ไฟล์จากช่องทางอย่างเป็นทางการเท่านั้น

### โปรแกรมป้องกันไวรัสบล็อกระบบจับภาพหน้าจอ [#startup-capture-blocked]

เปิดประวัติการป้องกันในโปรแกรมป้องกันไวรัส อนุญาตรายการล่าสุดที่ถูกบล็อก แล้วกด **ลองอีกครั้ง**
ถ้าใช้ Windows Security ให้ไปที่ **Virus & threat protection** → **Protection history**
ถ้าไม่มีรายการที่ถูกบล็อก ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### Windows จับภาพหน้าจอไม่ได้ [#startup-capture-unsupported]

อัปเดต Windows ที่ **Windows Update** ใน **Settings** และอัปเดตไดรเวอร์การ์ดจอจากเว็บไซต์ของผู้ผลิต (NVIDIA, AMD หรือ Intel) แล้วกด **ลองอีกครั้ง**
ถ้าข้อความบอกว่า Windows ไม่อนุญาตให้จับภาพหน้าจอ ปัญหานี้ไม่เกี่ยวกับโปรแกรมป้องกันไวรัส และมักพบใน Windows ที่ถูกดัดแปลงหรือตัดฟีเจอร์ออก ต้องใช้ Windows 10 หรือ 11 ฉบับปกติที่อัปเดตแล้ว

### บริการจับภาพหน้าจอของ Windows ถูกปิด [#startup-capture-service]

มักเกิดจากโปรแกรมปรับแต่ง Windows

1. รีสตาร์ทเครื่อง
2. เปิด AR Launcher
3. กด **ใช่** (Yes) เมื่อ Windows ขออนุญาต AR Launcher จะเปิดบริการนี้กลับมาให้

### ปิดการควบคุมบัญชีผู้ใช้ (UAC) ไว้ [#startup-uac-off]

<Callout type="warning">
  **ถ้าเครื่องนี้ไม่ได้ติดตั้ง Windows จากไฟล์ของ Microsoft** เช่น Windows ที่มีคนดัดแปลงหรือตัดฟีเจอร์ออก
  **หรือเคยใช้โปรแกรมปรับแต่งที่ปิดบริการของ Windows**
  การเปิด UAC กลับมาอาจทำให้เครื่องขอสิทธิ์ผู้ดูแลระบบไม่ได้อีก และอาจต้องเข้า Safe Mode เพื่อแก้กลับ
  ถ้าไม่แน่ใจ ให้ติดต่อทีมงานก่อนทำ
</Callout>

เครื่องนี้ปิด User Account Control (UAC) ไว้ ซึ่งน่าจะเป็นเหตุที่ Windows ไม่อนุญาตให้จับภาพหน้าจอ ต้องใช้บัญชีผู้ดูแลระบบ (Administrator) ของเครื่องนี้ในการแก้

1. กด **เปิดการตั้งค่า UAC** ใต้ข้อความ ถ้าหน้าต่างไม่ขึ้น ให้กดปุ่ม Windows + R พิมพ์ `UserAccountControlSettings` แล้วกด Enter
2. เลื่อนแถบไปที่ระดับที่สองจากบนสุด ซึ่งเป็นค่าเริ่มต้นของ Windows แล้วกด **ตกลง** (OK)
3. รีสตาร์ทเครื่อง แล้วเปิด AR Launcher อีกครั้ง

### ใช้บัญชี Administrator ที่มากับ Windows [#startup-builtin-admin]

<Callout type="warning">
  **ถ้าเครื่องนี้ไม่ได้ติดตั้ง Windows จากไฟล์ของ Microsoft** เช่น Windows ที่มีคนดัดแปลงหรือตัดฟีเจอร์ออก
  **หรือเคยใช้โปรแกรมปรับแต่งที่ปิดบริการของ Windows**
  การเปิด UAC กลับมาอาจทำให้เครื่องขอสิทธิ์ผู้ดูแลระบบไม่ได้อีก และอาจต้องเข้า Safe Mode เพื่อแก้กลับ
  ถ้าไม่แน่ใจ ให้ติดต่อทีมงานก่อนทำ
</Callout>

เครื่องนี้เข้าใช้งานด้วยบัญชี Administrator ที่มากับ Windows และปิด UAC ไว้ ซึ่งน่าจะเป็นเหตุที่ Windows ไม่อนุญาตให้จับภาพหน้าจอ

1. กด **คัดลอกคำสั่ง** ใต้ข้อความ
2. กดปุ่ม Windows + R พิมพ์ `cmd` แล้วกด Enter
3. คลิกขวาในหน้าต่างสีดำเพื่อวางคำสั่ง แล้วกด Enter
4. รีสตาร์ทเครื่อง แล้วเปิด AR Launcher อีกครั้ง

คำสั่งนี้เปิด UAC ให้เครื่องนี้และบัญชีนี้ ถ้าคัดลอกไม่ได้ ให้คัดลอกจากด้านล่าง

```txt
cmd /c "reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v EnableLUA /t REG_DWORD /d 1 /f && reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v FilterAdministratorToken /t REG_DWORD /d 1 /f"
```

ถ้าทำแล้วยังไม่หาย ให้เข้าใช้งาน Windows ด้วยบัญชีผู้ดูแลระบบปกติ ไม่ใช่บัญชี Administrator ที่มากับ Windows
ถ้าตอนติดตั้ง AR Launcher [เลือกให้ใช้ได้เฉพาะบัญชีเดิม](/th/ar-launcher/install#install-for-whom) ต้องติดตั้ง AR Launcher ใหม่ในบัญชีนั้นด้วย

### เปิดบริการ Application Information ก่อน [#startup-appinfo-off]

เครื่องนี้ปิด User Account Control (UAC) ไว้ ซึ่งน่าจะเป็นเหตุที่ Windows ไม่อนุญาตให้จับภาพหน้าจอ แต่บริการ Application Information ของ Windows ถูกปิดอยู่ด้วย
เมื่อเปิด UAC แล้ว Windows ใช้บริการนี้ขอสิทธิ์ผู้ดูแลระบบทุกครั้ง ถ้าเปิด UAC ก่อน เครื่องจะขอสิทธิ์ผู้ดูแลระบบไม่ได้ จึงต้องเปิดบริการนี้ก่อน ต้องใช้บัญชีผู้ดูแลระบบ (Administrator) ของเครื่องนี้ในการแก้

1. กด **คัดลอกคำสั่ง** ใต้ข้อความ
2. กดปุ่ม Windows + R พิมพ์ `cmd` แล้วกด Enter
3. คลิกขวาในหน้าต่างสีดำเพื่อวางคำสั่ง แล้วกด Enter ถ้าขึ้นว่า `[SC] ChangeServiceConfig SUCCESS` แปลว่าสำเร็จ
4. กด **ลองอีกครั้ง** ไม่ต้องรีสตาร์ทเครื่อง แล้วทำตามข้อความถัดไปเรื่อง UAC

คำสั่งนี้ตั้งบริการ Application Information กลับเป็น Manual ซึ่งเป็นค่าเริ่มต้นของ Windows ถ้าคัดลอกไม่ได้ ให้คัดลอกจากด้านล่าง

```txt
sc.exe config Appinfo start= demand
```

ถ้าขึ้นว่า `Access is denied` ให้ทำจากบัญชีผู้ดูแลระบบของเครื่องนี้

### Windows บนเครื่องนี้ขอสิทธิ์ผู้ดูแลระบบไม่ได้ [#startup-elevation-missing]

เครื่องนี้ปิด User Account Control (UAC) ไว้ ซึ่งน่าจะเป็นเหตุที่ Windows ไม่อนุญาตให้จับภาพหน้าจอ
แต่ Windows บนเครื่องนี้ไม่มีส่วนที่ใช้ขอสิทธิ์ผู้ดูแลระบบ คือบริการ Application Information หรือไฟล์ `consent.exe` มักพบใน Windows ที่มีคนดัดแปลงหรือตัดฟีเจอร์ออก

<Callout type="error">
  **อย่าเปิด UAC บนเครื่องนี้** ถ้าเปิด เครื่องจะขอสิทธิ์ผู้ดูแลระบบไม่ได้อีก รวมถึงการปิด UAC กลับ และอาจต้องเข้า Safe Mode เพื่อแก้
</Callout>

ทางแก้คือใช้ Windows 10 หรือ 11 ฉบับปกติที่ติดตั้งจากไฟล์ของ Microsoft ถ้าไม่แน่ใจ ให้[ส่งไฟล์ log ให้ทีมงาน](/th/ar-launcher/send-log)

### FiveM เปิดอยู่ตอนเปิด AR Launcher [#startup-fivem-running]

ต้องปิด FiveM ก่อนเริ่มใช้งาน AR Launcher กด **ปิด FiveM** แล้ว AR Launcher จะปิด FiveM และตรวจความพร้อมใหม่เอง
ถ้าปิดไม่สำเร็จ ให้ปิด FiveM จาก Task Manager แล้วกด **ลองอีกครั้ง**

### ไฟล์ตั้งค่าของ GTA V [#startup-gta-settings]

- ไม่พบไฟล์ตั้งค่า: เปิดเกมผ่าน FiveM หนึ่งครั้งเพื่อให้เกมสร้างไฟล์ แล้วกด **ลองอีกครั้ง**
- ไฟล์ตั้งค่าเสียหายหรืออ่านไม่ได้: เข้าเกมผ่าน FiveM แล้วบันทึกการตั้งค่ากราฟิกอีกครั้ง
- ตรวจสอบการตั้งค่ากราฟิกไม่สำเร็จ: กด **ลองอีกครั้ง**

## ระบบแอนตี้ชีตไม่ทำงาน [#anticheat-not-running]

หน้าต่างนี้ขึ้นเมื่อกดเชื่อมต่อเซิร์ฟเวอร์ที่รับเฉพาะเครื่องที่ระบบแอนตี้ชีตทำงานอยู่
ข้อความในหน้าต่างจะบอกสาเหตุ ดูหัวข้อย่อยที่ตรงกับข้อความนั้น

### โปรแกรมป้องกันไวรัสบล็อกไว้ [#anticheat-blocked-by-antivirus]

เปิดประวัติการป้องกันในโปรแกรมป้องกันไวรัส อนุญาตรายการล่าสุดที่ถูกบล็อก แล้วกด **ลองอีกครั้ง**
ถ้าใช้ Windows Security ให้ไปที่ **Virus & threat protection** → **Protection history**
ไม่ต้องปิดโปรแกรมป้องกันไวรัส ถ้ายังไม่ได้ ให้ถ่ายหน้าจอหน้าต่างนั้นส่งให้ทีมงาน

### ไฟล์ที่ระบบแอนตี้ชีตต้องใช้หายไป [#anticheat-files-missing]

ไฟล์อาจถูกลบไปหลังการติดตั้ง ให้ติดตั้ง AR Launcher ใหม่อีกครั้ง

### AR Launcher กำลังขออนุญาตจาก Windows [#anticheat-waiting-for-windows]

กด **ใช่** (Yes) เมื่อ Windows ถาม แล้วกด **ลองอีกครั้ง**
ถ้าไม่เห็นหน้าต่างของ Windows ให้ดูไอคอนที่กะพริบบนแถบงาน

### บัญชี Windows ไม่ใช่บัญชีผู้ดูแลระบบ [#anticheat-not-admin]

ใส่รหัสผ่านของบัญชีผู้ดูแลระบบ (Administrator) ของเครื่องนี้เมื่อ Windows ถาม แล้วกด **ลองอีกครั้ง**
ถ้าไม่ทราบรหัสผ่าน ให้เข้าใช้งาน Windows ด้วยบัญชีผู้ดูแลระบบ หรือขอให้เจ้าของเครื่องช่วย

### เครื่องตั้งค่าไม่ให้บัญชีนี้ขอสิทธิ์ [#anticheat-elevation-denied]

เข้าใช้งาน Windows ด้วยบัญชีผู้ดูแลระบบ (Administrator) ของเครื่องนี้ หรือขอให้เจ้าของเครื่องช่วย

## การเชื่อมต่อกับเซิร์ฟเวอร์ถูกบล็อก [#connection-blocked]

มีโปรแกรมบนเครื่องหรือในเครือข่ายของคุณบล็อกการเชื่อมต่อของ AR Launcher
ถ้าใช้ VPN หรือโปรแกรมเร่งความเร็วอินเทอร์เน็ต ให้ปิดโปรแกรมนั้น หรือตั้งค่าให้ยกเว้น AR Launcher
แล้วกด **ลองอีกครั้ง**

## บัญชี Steam ใน FiveM ไม่ตรงกับ AR Launcher [#steam-mismatch]

FiveM ผูกกับบัญชี Steam คนละบัญชีกับที่เข้าสู่ระบบ AR Launcher เซิร์ฟเวอร์จึงปฏิเสธการเชื่อมต่อ
แก้ได้สองทาง

- เปลี่ยนบัญชี Steam ในการตั้งค่าของ FiveM ให้เป็นบัญชีเดียวกับ AR Launcher แล้วกด **ลองอีกครั้ง**
  แล้ว AR Launcher จะเปิด FiveM ใหม่ให้
- หรือออกจากระบบ แล้วเข้าสู่ระบบ AR Launcher ด้วยบัญชีที่ FiveM ใช้

## ผูกบัญชี Steam กับ FiveM [#steam-link]

เซิร์ฟเวอร์นี้ต้องใช้บัญชี Steam ที่ผูกกับ FiveM และต้องเปิด FiveM ใหม่หลังผูกบัญชี AR Launcher จึงปิด FiveM ไปก่อน
กด **ลองอีกครั้ง** ถ้า FiveM ขอให้ผูกบัญชี Steam ให้ใช้บัญชีเดียวกับที่เข้าสู่ระบบ AR Launcher

## ยังเข้าเซิร์ฟเวอร์นี้ไม่ได้ [#cannot-join]

ข้อความในหน้าต่างจะบอกสาเหตุ ดูหัวข้อย่อยที่ตรงกับข้อความนั้น

### AR Launcher ไม่พบ FiveM [#fivem-not-found]

เปิด FiveM เองหนึ่งครั้ง รอจนถึงหน้าหลักแล้วปิด จากนั้นกด **ลองอีกครั้ง**

### ไม่พบไฟล์ตั้งค่าของ RedM [#redm-settings]

- ไม่พบไฟล์ตั้งค่า หรือไฟล์อ่านไม่ได้: เปิด RedM เองหนึ่งครั้ง รอจนถึงหน้าหลักเพื่อให้เกมเขียนไฟล์ตั้งค่าใหม่ แล้วปิด จากนั้นกด
  **ลองอีกครั้ง**

### เกมไม่ได้เปิดในโหมดตรวจไฟล์เกม (pure mode) [#pure-mode]

กด **ลองอีกครั้ง** เพื่อให้ AR Launcher เปิดเกมใหม่ อย่าเปิด FiveM เอง
ถ้าข้อความบอกว่าตรวจไม่ได้และยังเกิดขึ้นอีก ให้รีสตาร์ทเครื่องแล้วลองอีกครั้ง

### FiveM ไม่ได้อยู่ในช่องทางอัปเดตที่เซิร์ฟเวอร์กำหนด [#update-channel]

กด **ลองอีกครั้ง** แล้วรอให้ FiveM อัปเดตจนเสร็จ อย่าเปิด FiveM เอง

### FiveM อัปเดตตัวเองแล้วปิดไป [#fivem-updated]

ปิดหน้าต่างแจ้งข้อผิดพลาดของ FiveM แล้วกด **ลองอีกครั้ง**

### FiveM หยุดทำงานระหว่างเข้าเซิร์ฟเวอร์ [#fivem-stopped]

มักเกิดจาก FiveM แครช AR Launcher จึงปิดหน้าต่างเกมที่ค้างอยู่ กด **ลองอีกครั้ง**

## FiveM เปิดอยู่ [#fivem-open]

ดู[ถ้า FiveM เปิดอยู่แล้ว](/th/ar-launcher/play#fivem-already-open)

## ถูกระงับการใช้งาน [#blocked]

บัญชีนี้ถูกระงับการใช้งาน AR Launcher ถ้าคิดว่าเป็นความผิดพลาด ให้ติดต่อผู้ดูแลเซิร์ฟเวอร์

## ถูกเตะออกจากเกมระหว่างเล่น [#kicked]

<Callout type="info">
  ถ้า AR Launcher ถูกปิด แครช หรือเน็ตหลุด เซิร์ฟเวอร์จะเตะคุณออกจากเกม เปิด AR Launcher ค้างไว้ตลอดเวลาที่เล่น
</Callout>
