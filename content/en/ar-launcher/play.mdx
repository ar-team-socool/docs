# Joining a server

## Open AR Launcher [#open-launcher]

Every time AR Launcher opens, Windows asks with a yellow **Publisher: Unknown** prompt. Choose **Yes**.
The permission is for the anti-cheat only. AR Launcher and the game do not get it, and FiveM starts the same
way as when you open it yourself. Choose **Yes** only if you installed it from
[the places named on the install page](/en/ar-launcher/install#download).

With No, you cannot join a server that checks for the anti-cheat until you choose **Yes** when Windows asks
again as you press Connect. If you cannot see the prompt, look for the flashing icon on the taskbar.

## Connect to a server [#connect]

Pick a server and press **Connect**, then let AR Launcher open the game.

<Callout type="warning">
  Do not start FiveM yourself. On some servers AR Launcher closes a game it did not open.
</Callout>

### If FiveM is already open [#fivem-already-open]

AR Launcher cannot start the game while FiveM is open, and shows **FiveM is open**.
Press **Close FiveM and connect** and AR Launcher closes FiveM and connects you to the server.
A game in progress will be closed.

### Cancel while connecting [#cancel-join]

While AR Launcher is starting or connecting, press **Cancel connecting**, then **Cancel and close FiveM**.
AR Launcher closes FiveM and stops connecting. You can then pick a server and press **Connect** again.

## While you play [#while-playing]

<Callout type="error">
  **Keep AR Launcher open while you play.** If it is closed, crashes or loses its connection, the server
  kicks you out of the game.
</Callout>

## Updates [#updates]

Install it once. When a new version comes out, AR Launcher updates on its own, so there is no need to
download it again.

If you are playing on a server, restarting to update disconnects you immediately, and you will need to
reconnect.
