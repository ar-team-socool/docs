# Troubleshooting

The sections on this page are named after the messages AR Launcher shows, when it opens and when you
connect to a server. Find the one that matches what you see. If it still does not work after following the steps, [send your log file to the team](/en/ar-launcher/send-log).

## AR Launcher does not get past startup [#startup]

When AR Launcher opens it checks that everything is ready, one step at a time. If a step fails, a red
message under the logo says why. Find the section below that matches it.
If the message says an unexpected error occurred, a secure connection could not be set up, or the server
information could not be loaded, press **Try again**. If it keeps happening,
[send your log file to the team](/en/ar-launcher/send-log).

### No internet connection was found [#startup-internet]

Check that your PC is connected to the internet, then press **Try again**.

### Could not connect to AR Launcher [#startup-connection]

If you use a VPN, an internet booster or a custom DNS, turn it off, then press **Try again**.
If the message says your connection could not be confirmed, check your internet connection first, then
press **Try again**.

### This PC's date or time is wrong [#startup-clock]

The date and time this PC is using are shown under the message. Correct them through Windows rather than
setting the clock by hand.

1. Open Windows **Settings** and go to **Time & language** → **Date & time**.
2. Turn on **Set time automatically**.
3. If the time is still wrong, choose the **Time zone** for the country you are in, for example
   **(UTC+07:00) Bangkok, Hanoi, Jakarta** for Thailand. If you cannot choose one, turn off
   **Set time zone automatically** first.
4. Go back to AR Launcher and press **Try again**.

### An update is required, but no new version is available yet [#startup-update]

The installed version is older than the versions that may be used, and there is no newer version to update
to yet. This is not a problem with your PC, so reinstalling does not help.
Wait a while, then press **Try again**. If it keeps happening, contact the AR team.

### Reinstall AR Launcher [#startup-reinstall]

A file that screen capture needs is missing, or does not match the installed version of AR Launcher.
Download the installer from the [install page](/en/ar-launcher/install#download) and install again. Use a
file from the official channels only.

### Antivirus software is blocking screen capture [#startup-capture-blocked]

Open your antivirus protection history, allow the most recently blocked item, then press **Try again**.
If you use Windows Security, go to **Virus & threat protection** → **Protection history**.
If nothing there was blocked, [send your log file to the team](/en/ar-launcher/send-log).

### Windows cannot capture the screen, or a message about UAC [#startup-capture-unsupported]

These messages come from AR Launcher versions before 0.26.4: the ones about Windows screen capture, User Account Control (UAC), the Application Information service and the built-in Administrator account.

If you still see one of them, [download the latest AR Launcher](/en/ar-launcher/install#download) and install it.
You do not need to turn UAC on or run the commands this section used to give.

### FiveM or RedM is running when AR Launcher opens [#startup-fivem-running]

The game has to be closed before AR Launcher can start. Press **Close the game**, and AR Launcher closes
it and checks again by itself.
If it could not close the game, end it in Task Manager, then press **Try again**.

## The anti-cheat is not running [#anticheat-not-running]

This appears when you press Connect on a server that only admits PCs where the anti-cheat is running.
The message in the window says why. Find the section below that matches it.

### Antivirus software is blocking it [#anticheat-blocked-by-antivirus]

Open your antivirus protection history, allow the most recently blocked item, then press **Try again**.
In Windows Security, go to **Virus & threat protection** → **Protection history**.
Do not turn your antivirus off. If it still fails, send the team a screenshot of the window.

### A file the anti-cheat needs is missing [#anticheat-files-missing]

It may have been removed after installation. Reinstall AR Launcher.

### AR Launcher is asking Windows for permission [#anticheat-waiting-for-windows]

Choose **Yes** when Windows asks, then press **Try again**.
If you cannot see the Windows prompt, look for the flashing icon on the taskbar.

### Your Windows account is not an administrator [#anticheat-not-admin]

Enter the password of an administrator account on this PC when Windows asks, then press **Try again**.
If you do not know the password, sign in to Windows with an administrator account, or ask the owner of this PC.

### This PC does not let your account ask for permission [#anticheat-elevation-denied]

Sign in to Windows with an administrator account on this PC, or ask the owner of this PC.

## The connection to the server is blocked [#connection-blocked]

A program on your PC or network is blocking AR Launcher's connection.
If you use a VPN or an internet booster, turn it off or set it to exclude AR Launcher, then press **Try again**.

## FiveM or RedM is using a different Steam account [#steam-mismatch]

The game (FiveM or RedM) is linked to a different Steam account than the one signed in to AR Launcher, so
the server refused the connection. There are two ways to fix it:

- Link the same Steam account as AR Launcher in the game's settings, then press **Try again**.
  AR Launcher restarts the game for you.
- Or sign out, and sign in to AR Launcher with the account the game uses.

## Link your Steam account to FiveM or RedM [#steam-link]

This server requires a Steam account linked to the game, and the game has to restart after linking, so
AR Launcher closed it. Press **Try again**. If the game asks you to link Steam, use the same account you
signed in to AR Launcher with.

## Could not join this server yet [#cannot-join]

The message in the window says why. Find the section below that matches it.

### AR Launcher could not find FiveM or RedM [#fivem-not-found]

Open that game yourself once, wait for its main screen, close it, then press **Try again**.

### GTA V's settings file was not found [#startup-gta-settings]

The settings file was not found, or could not be read: start the game through FiveM once so it writes its
settings file again, then press **Try again**.

### Your graphics settings could not be checked [#settings-unchecked]

Press **Try again**. If it still fails, check your internet connection, then contact the AR team.

### RedM's settings file was not found [#redm-settings]

The settings file was not found, or could not be read: start RedM yourself once so it writes its settings
file again. Close it, then press **Try again**.

### The game was not started in pure mode [#pure-mode]

Press **Try again** so AR Launcher starts the game again. Do not start the game yourself.
If the message says it could not check, and it happens again, restart your PC and try again.

### FiveM or RedM is not on the update channel the server requires [#update-channel]

Press **Try again** and let the game finish updating. Do not start the game yourself.

### FiveM or RedM updated itself and closed [#fivem-updated]

Close the game's error window, then press **Try again**.

### FiveM or RedM stopped while joining [#fivem-stopped]

This is usually a crash of the game, so AR Launcher closed the game window it left behind. Press **Try again**.

## FiveM or RedM is open [#fivem-open]

See [If FiveM or RedM is already open](/en/ar-launcher/play#fivem-already-open).

## Blocked [#blocked]

This account has been blocked from using AR Launcher. If you believe this is a mistake, contact the server
administrators.

## Kicked out of the game while playing [#kicked]

<Callout type="info">
  If AR Launcher is closed, crashes or loses its connection, the server may kick you out of the game. Keep
  AR Launcher open the whole time you play.
</Callout>
