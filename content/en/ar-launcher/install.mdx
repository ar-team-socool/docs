# Download and install

<Steps>

### Download the installer [#download]

Open [ar-launcher.wip-town.com](https://ar-launcher.wip-town.com/?lang=en) and press **Download**.
Download it only from there or from [AR Launcher's GitHub page](https://github.com/ar-team-socool/fivem-launcher-releases).
Both give you the same file. A copy from anywhere else is not ours.

### Run the file you downloaded [#run-installer]

You may see the prompts in the [next section](#installer-prompts) while installing. All of them are normal.

### Sign in with Steam [#sign-in]

Open AR Launcher and press **Sign in with Steam**. AR Launcher opens Steam's sign-in page in your browser.
Finish signing in there, then come back to AR Launcher.

If no browser opens, press **Copy the link** and paste it into your browser's address bar.

### Accept the Terms [#accept-terms]

Read the **Terms & Conditions** to the end, then press **Accept Terms**.
The [Privacy Notice](https://ar-launcher.wip-town.com/privacy) is linked from the same page.

</Steps>

<Callout type="warning">
  Use the same Steam account that is linked in FiveM or RedM. If they differ, the server refuses the
  connection. See [FiveM or RedM is using a different Steam account](/en/ar-launcher/troubleshooting#steam-mismatch).
</Callout>

## Prompts you may see while installing [#installer-prompts]

### An “Open File - Security Warning” window [#security-warning]

Choose **Run**. Windows shows this for every program downloaded from the internet.

### A blue “Windows protected your PC” screen [#smartscreen]

Choose **More info**, then **Run anyway**.
Only do this for a file you downloaded from [the places named above](#download). If it came from anywhere
else, delete it and download it again.

### The installer asks who to install it for [#install-for-whom]

Leave it on **Only for me**. The other option needs administrator rights.

### A yellow prompt saying Publisher: Unknown [#publisher-unknown]

It appears every time AR Launcher opens. Choose **Yes**. See
[Joining a server](/en/ar-launcher/play#open-launcher) for details.

### Your antivirus blocks it [#antivirus]

Open your antivirus protection history. In Windows Security, go to **Virus & threat protection** →
**Protection history**, allow the most recent blocked item, then try again.

### Smart App Control blocks it [#smart-app-control]

This happens on Windows 11 only. See [Smart App Control is blocking AR Launcher](/en/ar-launcher/troubleshooting#smart-app-control)
for how to check and what to do.

### Nothing happens when you open the file [#nothing-opens]

The file is not broken. If it has not finished downloading, wait until your browser says it is done, then
open it again. If it has, the prompt may be behind another window: check the taskbar before opening the file
again.

## Uninstall [#uninstall]

Go to **Settings** → **Apps** → **Installed apps** and uninstall **AR Launcher**.
On Windows 10 this list is called **Apps & features**.
