# Download and install

<Steps>

### Download the installer [#download]

Open [ar-launcher.wip-town.com](https://ar-launcher.wip-town.com/?lang=en) and press **Download**.

### Run the file you downloaded [#run-installer]

You may see the prompts in the [next section](#installer-prompts) while installing. All of them are normal.

### Sign in with Steam [#sign-in]

Open AR Launcher and press **Sign in with Steam**. The launcher opens Steam's sign-in page in your browser.
Finish signing in there, then come back to the launcher.

If no browser opens, press **Copy the link** and paste it into your browser's address bar.

### Accept the Terms [#accept-terms]

Read the **Terms & Conditions** to the end, then press **Accept Terms**.
The [Privacy Notice](https://ar-launcher.wip-town.com/privacy) is linked from the same page.

</Steps>

<Callout type="warning">
  Use the same Steam account that is linked in FiveM. If they differ, the server refuses the connection.
  See [FiveM is using a different Steam account](/en/ar-launcher/troubleshooting#steam-mismatch).
</Callout>

## Prompts you may see while installing [#installer-prompts]

### A blue “Windows protected your PC” screen [#smartscreen]

Choose **More info**, then **Run anyway**.

### The installer asks who to install it for [#install-for-whom]

Leave it on **Only for me**. The other option needs administrator rights.

### A yellow prompt saying Publisher: Unknown [#publisher-unknown]

It appears every time the launcher opens. Choose **Yes**. See
[Joining a server](/en/ar-launcher/play#open-launcher) for details.

### Your antivirus blocks it [#antivirus]

Open your antivirus protection history. In Windows Security, go to **Virus & threat protection** →
**Protection history**, allow the most recent blocked item, then try again.
